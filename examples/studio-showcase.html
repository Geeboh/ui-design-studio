02 / Component samples

Predictable building blocks.

Buttons are intentionally disabled in this static specimen. Production controls need real actions, states and keyboard tests.

Interaction specification example

Production dialogs receive an accessible title, predictable initial focus, contained keyboard navigation, Escape behaviour and focus restoration. Critical state changes have a readable status and recovery path.
