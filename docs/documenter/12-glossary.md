# Glossary

| Term | Meaning |
| --- | --- |
| Design run | Persisted, resumable workflow state under configured run paths. |
| Design server | Runtime service for run status, records, artwork, evidence, and dashboard APIs. |
| Dashboard connection | Authenticated local connection identified by instance, project, URL, and optional run. |
| Director | Session role that owns a run and may export Pi Tasks state. |
| OMP | Host environment that loads skills, commands, agents, extensions, and tools. |
| Phase gate | Required evidence or approval condition between workflow phases. |
| Pi Tasks | Host task/progress state observed and exported by the extension. |
| Theme module | Versioned CSS/SVG design-token package with manifest, budget, and quality rules. |
| Trusted LAN | Documented non-public network boundary for dashboard access. |
| UAT | User acceptance testing; existing records mark some UAT as deferred. |
| Yolo mode | Autonomous design mode selected by /ui-yolo; it does not waive evidence or safety contracts. |
