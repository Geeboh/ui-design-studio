# PRISM Studio 2.0.7

PRISM Studio 2.0.7 adds a measured Optimization dashboard.

The Optimization tab exposes Balanced, Maximum savings, Lossless and Custom presets; quality and compression settings; optional pngcrush, jpegoptim, optipng and svgomg/svgo capabilities; built-in HTML/CSS/JS/JSON/text/SVG transforms; gzip/Brotli artifacts; recommendations; tool availability; operation details; and real before/after bytes. Representative examples cover PNG, SVG, HTML, CSS, JavaScript, JSON, text and PDF.
