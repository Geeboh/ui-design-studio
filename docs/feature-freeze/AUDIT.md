# Technical audit

UI Design Studio supplies project-local OMP skills, a Python workflow engine, authenticated HTTP dashboards, and a local stdio MCP adapter. The expected workload is a small private design team. Native-platform certification and public-internet deployment are outside the evidence.

The initial audit inventoried 116 baseline tracked paths. The final candidate set has 140 uniquely reconciled paths in the [inventory](INVENTORY.md). Generated historical archives and screenshots remain integration evidence, not rewritten product sources.

The inherited audit registered 20 confirmed findings. Current revalidation additionally records FF-021 through FF-043. [The register](DEFECT-REGISTER.md) owns every severity, root cause, consumer impact, correction, regression risk, verification, and commit. Its current statuses take precedence over earlier completion claims.

The principal defects involved bounded scope receiving full release acceptance, nonregular files blocking lifecycle operations, retained artwork diverging from signed approvals, private environment files entering distributions, and failed checksum publication changing existing artifacts. Smaller defects affected critical-state coverage, worker contracts, resume invalidation, run selection, browser restoration, keyboard focus, and documentation provenance.

Corrections remain in existing shared validators, ownership/lifecycle structures, and packaging boundaries. No runtime dependency or product feature was added. Existing APIs and schemas remain, except that invalid acceptance, path, special-file, and permission-metadata behavior is corrected explicitly.

Independent review found incomplete artwork-ID and nested-example protections. Both were reproduced before correction. A proposed extension guard was rejected because existing tests explicitly require genuinely new runs to auto-open; the reviewer withdrew that concern. Existing unopened peers no longer masquerade as newly created runs.

Passing tests do not establish absence of defects. Final readiness, exact gate results, and external limitations are recorded separately.

## Current remediation

Fresh correct-target review identified lost repository provenance for nested configured run roots, serialized concurrent landing probes, explicit empty artifact-list widening, and a source ZIP template-directory privacy exception.
Actual consumer regressions reproduced these defects before correction.
The protocol test helper also shadowed unittest assertion failures and was renamed.
Current corrections retain explicit ownership rather than inventing broader path inference or liveness caches.
A wrong-target engine review of excluded user edits was rejected and replaced.
All current review findings and full-suite results are reconciled in the register and release assessment. External acceptance and recovery uncertainty remain explicit.

A fresh whole-engine review additionally found cross-project registration, missing assessment-report binding, whitespace self-review, unchecked quoted CSS image sources and incomplete resume consumers. New behavioral tests reproduced each defect. A real Chromium probe also fetched an intercepted remote resource supplied through a quoted custom property and `image-set(var(...))`; the static subset now rejects direct resource-variable substitution.

The proposed missing-themes-parent scaffold defect was disproved by a successful real `theme_new` and `check_theme` invocation. No scaffold correction was applied.

Independent correction review found four remaining lexical/URL and resume-inventory gaps. All four were reproduced. Actual Chromium confirmed remote fetching through quoted comment markers, browser bad-string recovery and leading URL whitespace. Quote-aware lexical validation and a shared whitespace boundary close those cases. Resume snapshots now use recorded context/routing paths rather than fixed filenames. The focused engine suite passed 85 tests and 48 subtests after correction.

The final CSS review identified unquoted URL comment markers, environment fallback substitution and recoverable EOF URLs. Validator regressions and locally intercepted Chromium requests confirmed all three. URL tokens now remain atomic during preprocessing, direct image-source positions admit only audited static functions, and unfinished functions fail closed. All final CSS review findings have parent-verified corrections; no subsequent zero-finding independent CSS verdict is claimed.
