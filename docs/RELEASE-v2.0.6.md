# PRISM Studio 2.0.6

PRISM Studio 2.0.6 adds authenticated structured reference intake to the dashboard.

References support websites, PDFs, text, images, office/archive downloads and explicit categories: Reference, Design, Concept and Inspiration. Each upload stores immutable bytes, metadata, SHA-256 identity and notes under the selected run. HTML and SVG previews are sanitized. Unsupported preview types remain downloadable. Uploads are limited to 8 MiB and never retain bearer tokens.
