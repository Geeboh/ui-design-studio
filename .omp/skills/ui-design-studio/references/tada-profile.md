# Compatibility note: project requirements

This path is retained for older installed links. UI Design Studio no longer selects project requirements through a named profile.

Read [project-context.md](project-context.md), then the target project's current instructions, requirements, architecture decisions, task records and actual implementation. Apply the same procedure to TADA and to every other project. Do not infer geography, hardware, modules, offline requirements or publication rules from the project name.

If an older prompt includes `profile=tada`, use it only as a deprecated hint to check the intended project identity. It cannot supply, override or waive the project's requirements. Preserve legacy run records and their original required gates when resuming; resolve any change against the project's current authoritative sources.
