# Create concepts and complete mockups

Paste into OMP from the target project root. Change `mode=guided` to `mode=yolo` if you delegate concept and mockup decisions.

```text
Read .omp/skills/ui-design-studio/SKILL.md. Run mode=guided with models=auto-models for the complete existing interface, stopping after the Design phase.

Derive constraints from the project's current instructions, requirements, architecture and design system; no profile is required. Assess usability, inventory every relevant page/dialog/state, and prepare coherent concept alternatives with palettes, typography, spacing, icons, components and storyboards.

Present the alternatives for my selection, then create complete full-page/dialog mockups and interaction specifications for the agreed scope. Inspect their actual rendered output and include applicable narrow layouts, loading/empty/error/permission/offline states and keyboard/focus behaviour. Use a shared visual contract and independent critique.

After Design approval, package the design artifacts and specifications as a design-only draft handoff. Include the context, assessment, decisions, coverage index, implementation considerations and known gaps. Do not implement application changes, register a theme or alter its default in this run. Do not claim production verification from a mockup preview.
```
