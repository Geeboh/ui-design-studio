# Assess without redesigning

Paste into OMP from the target project root. Narrow the scope in the message when needed.

```text
Read .omp/skills/ui-assess/SKILL.md and the shared UI Design Studio instructions. Perform an assessment-only run for the complete existing UI using models=auto-models.

Read the project's instructions, requirements, source and existing design system; derive and record the applicable context without requiring a profile. Inventory the actual pages, dialogs, states and primary tasks. Inspect usability, human factors, hierarchy, typography, colour, whitespace, accessibility, responsive behaviour, consistency, feedback, failure/recovery, offline requirements and measurable performance.

Use bounded specialist assessment roles and separate observed evidence from expert judgement and unknowns. Produce a usable report with priorities, confidence, recommendations, expected tradeoffs and verification steps. Record unavailable runtime/rendering checks honestly.

Stop when the requested assessment and recommendations are complete. Save the report and supporting inventory/evidence, but do not implement application UI changes, register a theme or mark later design/release phases passed. Preserve project Git policy and unrelated work.
```
