# Resume goal-managed design work

If the correct OMP goal still exists and is paused, use its native resume command:

```text
/goal resume
```

If the goal is no longer present but the Studio dossier remains in the project, paste the objective below. It resumes that dossier rather than starting the redesign again. Identify the real run directory when several could match.

```text
/goal Read .omp/skills/ui-design-studio/SKILL.md and resume the latest relevant incomplete UI Design Studio run in this project. Preserve its scope, decision mode, model policy, theme action, approved direction and valid earlier decisions. Re-read current project requirements, verify context, actual model routing and evidence freshness, and continue the next unmet dependency through the agreed final deliverables. If an incomplete legacy 1.0 dossier needs the current workflow, perform its documented linked 1.1 continuation with init-run, retaining the original path/digest, valid theme identity/action and existing scaffold. Carry forward only safe useful artifacts and authentic still-valid decisions, reconcile coverage, resolve current context/model routing, retain required offline constraints, and obtain fresh evidence and final acceptance; never import the old final acceptance. The new model helpers operate only on the continuation. Do not require manual schema edits. Use bounded specialist workers and independent review. Do not create an unrelated duplicate run or repeat approved concept selection without a material change. Preserve project Git/release policy. Complete all independent work and record genuine blockers precisely. Mark this goal complete only after the full agreed scope is verified and documented.
```

The resume objective does not silently convert a guided run into YOLO. To delegate the remaining aesthetic decisions, explicitly add that instruction. It also does not silently change `current-model` to `auto-models`; request a policy change if you want one and preserve the historical assignments.
