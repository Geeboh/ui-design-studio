# Resolve a failed PRISM verification gate

Read the current source identity, gate receipt, complete relevant logs, captured reports and assigned acceptance cases. Establish the actual failure before proposing a fix. Distinguish product defects, test defects, missing prerequisites, stale evidence and unsupported target scope.

Repair the cause within owned scope, preserve regression coverage and rerun affected checks. Broaden testing only when the change creates a concrete cross-boundary risk or a required gate demands it. Do not change expected results, delete checks or mark failed cases inapplicable merely to obtain a pass.

If source changes, record a new candidate identity and renew affected evidence/review. Keep human participant research deferred. For a missing required tool or access, finish independent work and leave a precise recovery action. Update progress with the observed outcome, not an optimistic completion estimate.
