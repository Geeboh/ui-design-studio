# PRISM Studio

**Working name:** PRISM Studio  
**Product line:** UI Design Studio 2.0  
**Promise:** From intent to a clear, approved interface.

The name fits the central workflow: turn one broad design intention into visible, reviewable components, preserve the decisions that are already sound, and bring the result back together into a coherent product. It is a working product identity, not a claim about trademark or domain availability.

## Naming in the rebuild

Use “PRISM Studio” in the refreshed dashboard and product narrative. Keep the existing repository, Python package, CLI entry points, MCP integration and `ui-*` skill aliases during the compatibility period. Renaming every public surface would create migration work without improving the design workflow. Document any later deprecation with actual replacements and a supported transition.

Distinguish the **PRISM Studio Rebuild Pack 1.0.0** from the target **UI Design Studio 2.0.0** release. The pack is the implementation handoff; its version does not claim the application already exists.

## Visual direction

Use a calm studio workspace with a strong typographic hierarchy, neutral working surfaces and a restrained spectral accent. Let the artifact being reviewed carry the visual emphasis. Color should reinforce clear text and shape cues for accepted, stale, blocked and pending states; it must not be their only signal.

Respect the active theme and existing product tokens. Derive specific colors, spacing, contrast and interaction states from the implemented token system, then verify them. A decorative prism motif is optional and should not compete with an image comparison or introduce a new asset dependency into the critical path.

## Voice

Name the object, its state and the useful next action. “Header approved. Footer needs a revision.” is better than a generic success banner. Explain budget and stale-decision failures with the actual amount or dependency. Keep technical diagnostic detail available where it helps recovery, while leaving the main workflow understandable without reading internal identifiers.
